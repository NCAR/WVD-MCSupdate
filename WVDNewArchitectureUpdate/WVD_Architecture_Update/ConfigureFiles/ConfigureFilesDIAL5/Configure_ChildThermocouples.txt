This file is used to define the initial state of the MPD thermocouple labview program.

### This is where the Labview program should find the thermocouples. The elements here
### are: 1) IP Address, 2) Port, 3) Communication timeout in [ms], 4) Header bytes, and
### 5) Bytes to read.
Thermocouple Comm Port;;
192.168.0.165;502;3000;-1;-1;;

### These are miscellaneous variables that are read and used as default values
### by the thermocouple program. These are currently: 1) The update period of the
### thermocouples in seconds, 2) The number of measurements to save, 3) The number of
### thermocouples present, 4) The thermocouple to use for controlling automatic 
### heating, 5) The minimum temperature before automatic heating, and 6) Whether to
### allow automatic heating.
Child Variables;;
8;900;8;3;10;1;;

### Locations of the thermocouples in the module. For translation of the numbers
### see TypeDef_ThermocoupleLocations.ctl.
Thermocouple Locations;;
2;10;3;5;6;7;8;9;;

### File paths to the data storage and data logging locations and functions. The order is
### 1) Where to write the raw data, 2) What base name to call the thermocouple data files,
### 3) What base name to call the logging files, 4) Where to find the user logging program,
### and 5) Where to find the user permissions program.
FilePaths;;
.\Data\Housekeeping\;
HousekeepingV2;
HKLogging;
.\ContainerResources.llb\Log_SetUserComment.vi;
.\ContainerResources.llb\Idle_Password.vi;;

### This is where the Labview program should find the switch that turns on heaters. The elements
### are: 1) IP Address, 2) Port, 3) Communication timeout in [ms], 4) Header bytes, and
### 5) Bytes to read.
Switch IP Address;;
192.168.0.140;1618;3000;-1;30;;
